# OBIS-LAC
OBIS-LAC (Red de Nodos del Sistema de Información sobre Biodiversidad Oceánica para América Latina y el Caribe)

OBIS-LAC (Ocean Biodiversity Information System – Latin America and the Caribbean) es la red regional del Sistema de Información sobre Biodiversidad Oceánica (OBIS), un programa de la Comisión Oceanográfica Intergubernamental de la UNESCO (COI-UNESCO). Su objetivo es fortalecer la movilización, estandarización, publicación y acceso abierto a los datos sobre biodiversidad marina generados en América Latina y el Caribe.
